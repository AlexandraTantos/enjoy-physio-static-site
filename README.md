About the website
EnjoyPhysiotherapy is a website representing a physiotherapy clinic that offers services for recovery, prevention, and improvement of physical condition. Services include physiotherapy, electrotherapy, therapeutic massages, post-operative recovery programs, and specialized packages for athletes.

Role of the pages
- Home: Provides information about the company, services, and packages. The navigation bar contains a list of links to the application pages and links to social networks, and the footer contains the company's contact details and address.
- Services: Each service is presented in detail, along with the available facilities.
- Prices: Table with a complete list of services and packages along with the time and price for each.
- Contact: Form to contact the company.

What is implemented with JS
- Dynamic generation of promotional packages on the home page (from the data.js file)
- Carousel for images in Services, where we added buttons for next and prev
- Calculation for the promotional price (Exercise + Massage + Electro) with a 20% discount

How to navigate the page
- Use the navigation menu to easily access all the main pages of the website
- Click the Read More button on the Home page to go directly to the Services page
- In Services,I implemented an image carousel; you can test the prev and next buttons
- Automatic calculation of the promotional price in Prices
- Responsive pages on mobile/tablet
